## これはなに？

私がほしいと思う細かい機能を詰め込んだ、Windows向けのツール集です。     
C#で書かれており、Win32 APIやらなんやらを叩いてシステムの設定を変えたり変えなかったりします。

現在は以下の機能があります:

- 離席モード
    - ノートPC向けのモードで、設定されている対象（AC接続時 / バッテリー接続時）に対して、ノートPCの画面を閉じてもスリープしないように設定します。
    - 同時に、スリープ防止モードも有効になり、放置状態によるPCの自動スリープを防止することで、離席してもエージェント等を継続して動作させることができるようになります。
- スリープ防止モード
    - 離席モードの画面を閉じた場合の設定を抜いたバージョンです。PowerToysのAwake機能に相当します。PCを放置してもスリープしなくなりますが、画面を閉じると（設定で手動で変更していない場合）スリープします。

## 開発お役立ち情報

このプロジェクトはmise前提です。miseを使いたくない人はAIに聞いたりして読み替えてくださいね。

### ツールのインストール

.NET SDK 10がインストールされます

```
mise install
```

### テストビルド

テスト用のビルドを作成します

```
mise run build
```

### 本番ビルド

.NETをバンドルした単体実行可能なexeを作成します

```
mise run publish
```
